# TP Angular — Gestion de tâches

Application réalisée avec Angular et TypeScript dans le cadre du TP 2.

## Fonctionnalités
- Ajouter, modifier et supprimer des tâches.
- Marquer une tâche comme faite ou à faire.
- Rechercher, filtrer et trier les tâches.
- Sauvegarder les tâches avec localStorage.
- Afficher les statistiques sur une page dédiée.

## Lancement
Dans le dossier du projet :

```bash
cd tp2
npm start
```

Ouvrir l’adresse indiquée dans le terminal.

## Technologies
Angular, TypeScript, Signals, Reactive Forms et Angular Router.
